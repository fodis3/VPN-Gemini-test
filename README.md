# VPN Gemini 4.0.5 для Android

Нативный Android-клиент настольного тестера: Kotlin, Jetpack Compose и Material 3 Expressive.
Android 8.0+, ARM64 / x86_64. Приложение направляет через сервер только свои проверочные
запросы. Общесистемный VPN и root не требуются.

## Повтор QUIC в 4.0.5

При `message too long` / EMSGSIZE или транспортном тайм-ауте Hysteria2
выполняется одна повторная попытка: QUIC `initial_packet_size=1200`,
`disable_path_mtu_discovery=true`, `disable_chrome_parrot=true`. Последний
параметр нужен, потому что имитация Chrome переопределяет размер пакета.
Обычная попытка сохраняет штатный профиль. При повторе создаётся новое ядро
и новый SOCKS-порт; предыдущее ядро и HTTP-клиент закрываются.

Повтор не выполняется для полученных HTTP-результатов, блокировки Gemini,
CAPTCHA, ошибки пароля или других протоколов. После двух неудач сохраняется
ошибка/тайм-аут. Полное время складывает обе попытки, TLS-время относится
к успешному соединению. Повтор виден в журнале и описании карточки.
Из вывода ядра удаляются ANSI-коды цвета, пароли и obfs-пароль.

Настройки сверены с [QUIC Fields](https://sing-box.sagernet.org/configuration/shared/quic/)
и [Hysteria2](https://sing-box.sagernet.org/configuration/outbound/hysteria2/).
На предоставленном польском сервере Windows-сборка того же sing-box и Kotlin-код
получили HTTP 200 / Google PL / «Доступен» и в обычном, и в совместимом режиме.
Исходная ошибка Android в этой сети Windows не воспроизвелась. Прогон на
телефоне по-прежнему нужен для подтверждения именно на маршруте пользователя.

## Исправление Hysteria2 / TUIC в 4.0.4

Адрес VPN-сервера разрешается средствами Android перед запуском sing-box.
Полученные IPv4/IPv6 передаются в его DNS `hosts`; домен сервера, TLS SNI,
пароль и obfs сохраняются. Это устраняет зависимость отдельного executable от
`/etc/resolv.conf`: без него встроенный `local` резолвер пытается обращаться
к localhost:53 вместо DNS Android. Адрес Gemini продолжает передаваться через
туннель, прямой HTTP-запрос при ошибке не выполняется.

При SOCKS-ошибке в карточку добавляется вывод ядра с удалением учётных данных.
Проверка предоставленного пользователем Hysteria2-сервера через Windows-сборку
sing-box 1.14.3 и обновлённый Kotlin-код дала HTTP 200 / Google FI / «Доступен».
Ссылка и пароли в исходники не включены. Прогон на физическом Android здесь
не выполнялся: устройство не подключено.

Добавлен тест с настоящим локальным QUIC/Hysteria2-сервером, salamander и
несуществующим доменом, который разрешается только переданным bootstrap IP;
неверный пароль должен завершать запрос ошибкой.

## Проверка Gemini

Применяется схема настольной версии: Xray/sing-box → SOCKS5 → HTTPS-запрос
`https://gemini.google.com/app` → регион Google и признаки ограничения.

Исправлено извлечение `WIZ_global_data.vXmutd`. Google возвращает его не только
как строку `"US"`, но и как JSON-строку с сериализованным значением
`%.@.\"US\",...`. Новый парсер декодирует именно значение этого поля.
Коды из соседних полей не используются. Раньше Android пропускал такой формат,
поэтому оба реальных ответа с HTTP 200 получали одинаковый результат.

Статус «Доступен» требует успешного HTTPS-ответа и определённого разрешённого
региона Google без явного сообщения ограничения. Маркеры скриптов Gemini и
HTTP 200 без страны не дают положительный результат. Регион берётся из ответа,
а не из имени сервера, геолокации поставщика или заготовленного списка результатов.
Поэтому сервер с названием Finland может показывать US, если так его определяет Google.

Сверено на двух предоставленных пользователем конфигурациях: рабочий пример
получил US / «Доступен», нерабочий — RU / «Ограничение». Это проверено как
десктопным парсером, так и Kotlin-кодом Android на настоящих ответах через
Windows-сборку того же Xray. Сами конфигурации и токены в проект не включены.

Региональные правила сверены со [справкой Google для веб-версии](https://support.google.com/gemini/answer/13575153?hl=en)
20.10.2026: AF/BY/CU/IR/KP/RU/SY не перечислены, для CN указано Workspace only.
Этот список нужно актуализировать при изменении доступности сервиса.
Требование входа, CAPTCHA, HTTP 429, ошибки и тайм-ауты отображаются отдельно.

TLS-время — настоящее соединение с Gemini до завершения TLS через выбранный
туннель. Локальный SOCKS ACK не считается пингом удалённого сервера: Xray может
подтвердить его даже при недоступном удалённом узле. В карточке и CSV показаны
HTTP-код, регион Google, URL, размер/заголовок ответа и полное время проверки.

WebView удалён. Нет очереди скрытых браузеров и требования держать экран открытым.
Проверка работает через foreground service и подчиняется ограничениям Android.
Как и настольная версия, она не отправляет запрос генерации модели и не проверяет
доступ конкретного аккаунта Google.

## Возможности

- HTTPS-подписки, необязательный HWID, генерация UUID4, просмотр HWID.
- Передача HWID в `x-hwid` и совместимый User-Agent настольного клиента.
- Импорт текста, Base64 и JSON, системный выбор файла.
- VLESS, VMess, Trojan, Shadowsocks через Xray 26.3.27; Hysteria2/TUIC через sing-box 1.14.3.
- REALITY, TLS, WebSocket, gRPC, XHTTP, HTTPUpgrade; сохранение JSON outbound.
- Проблемные записи и дубликаты сохраняются, а не исчезают из подписки.
- Параллельные проверки 1–4, отмена, уведомление, прямое подключение.
- Поиск, фильтры, сортировка, журнал, копирование доступных конфигураций и CSV.
- Системные цвета Android 12+, светлая/тёмная тема, мягкий отключаемый тактильный отклик.
- Переходы по направлению вкладок, адаптация полей к клавиатуре.
- Штатный волнистый индикатор Material 3: волна между 10% и 95%, выпрямление в конце.

При ошибке подписки форма остаётся открытой. Ошибки HTTP, HTML-защита,
коды поставщика и Cloudflare 1002 различаются. Ошибка на сайте поставщика не
устраняется сменой HWID; уже привязанная подписка может требовать существующий HWID.

Конфигурации, результаты, ссылка подписки и HWID сохраняются только в памяти
сеанса. Настройки сохраняются. Конфигурации ядер временно находятся в приватном
cache и удаляются при завершении; остатки после аварийного завершения удаляются
при следующем запуске. CSV сохраняется только по команде пользователя.

## Сборка и проверка

Нужны JDK 17+, SDK Platform 37 / Build Tools 36 и Python 3. Указать SDK через
`local.properties` (`sdk.dir=...`) или `ANDROID_HOME`.

```powershell
python tools/fetch_cores.py
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Подпись debug предназначена
для локальной установки; для публикации нужен собственный release keystore.
Ядра установщик извлекает из `jniLibs` в исполняемый `nativeLibraryDir`.
Версии, официальные URL и SHA-256 записаны в `cores.lock.json`.

Проверки включают актуальный формат vXmutd, два противоположных региона с
одинаковым HTTP 200, отсутствие ложной страны из соседнего поля, настоящий
неработающий туннель Xray, HTTPS через SOCKS5 с задержкой TLS, конфигурации
шести протоколов и UI импорта/HWID/тем/навигации/прогресса в Robolectric.
`LiveParityTest` принимает временные конфигурации только из переменной
`VPN_GEMINI_LIVE_CASES`; без неё реальная сетевая проверка пропускается.
На физическом Android устройство в этом окружении не подключено; весь
сценарий APK на телефоне здесь не проверялся.

Официальный sing-box executable имеет ELF alignment 4 КБ; Xray — 16 КБ.
Совместимость sing-box на устройствах с размером страниц 16 КБ отдельно не
подтверждена; может потребоваться режим совместимости или пересборка ядра.
