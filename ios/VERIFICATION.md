# Проверка iOS 4.0.1

28.10.2026. Сборка и проверки GitHub Actions выполнены успешно.
[IPA и исходники](https://github.com/fodis3/VPN-Gemini-test/releases/tag/ios-v4.0.1).

- Архив для arm64 iPhone / iPad, минимальная версия iOS 17.0.
- Bundle ID: `ru.vpngemini.ios`, версия `4.0.1`, build `40001`.
- SHA-256 IPA: `5c0891bcd26ccf2073de84ce81ed0874645dd42fc2cf2b2d04183600db60440b`.
- Минимальная версия Go-фреймворка ядер также снижена до iOS 17.0;
  Xray 26.3.27 и sing-box 1.14.3 собраны одним Go runtime.
- Unit-тесты native engine прошли. Opt-in тест с реальными профилями в CI
  пропущен без конфигураций; частные ссылки и пароли в CI не передавались.
- Два UI-теста прошли на каждом из симуляторов iOS 26 и iOS 18.5:
  темы, импорт корректной конфигурации, переходы по вкладкам, настройки,
  генерация HWID и реальная проверка через закрытый VPN-порт.
- Неработающий туннель дал ошибку, без прямого обхода VPN.
- В симуляторный буфер передавалась только синтетическая конфигурация
  с нулевым UUID и localhost. Импорт выполнялся через системную вставку.
- Формат Mach-O arm64, версия и MinimumOSVersion проверены в скачанном IPA.

IPA не подписан сертификатом Apple. Для установки нужна подпись или
переподпись. На физическом iPhone и на iOS 17 выполнение отдельно
не проверялось; на iOS 17 проверена возможность сборки с этим deployment target.
При сворачивании приложения проверка останавливается. Общесистемный VPN
и постоянная фоновая работа не заявляются.
