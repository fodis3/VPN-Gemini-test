# Проверка iOS 4.0.0

20.10.2026 · исходники приложения: `98d946e4e6a1c1499366a4d102a93b66e1cba43f`.

**[Успешная сборка и тесты GitHub Actions](https://github.com/fodis3/test-vpn-ios/actions/runs/39403513109).**

- macOS 26, Xcode 26.6, архив для arm64 iPhone/iPad, минимум iOS 26.0.
- Метаданные IPA: `ru.vpngemini.ios`, версия `4.0.0`, build `40000`.
- SHA-256 IPA: `ebfcb6e6edec5dcde492979855f9ce4d22d06b9ddae2bc4c69bd76f913a15f81`.
- Два встроенных ядра собраны одной Go-библиотекой: Xray 26.3.27 и sing-box 1.14.3.
- Unit-тесты движка проходят на Windows и macOS. Сетевой тест с частными
  конфигурациями в CI пропускается; секреты в GitHub не передаются.
- На Windows текущий движок проверен на трёх реальных конфигурациях:
  рабочий VLESS → US / OK; нерабочий gRPC → RU / BLOCKED;
  рабочий Hysteria2 → PL / OK. URL, пароли и UUID пользователей не сохранены.
- В одном процессе действительно передан трафик через локальные VLESS и
  QUIC/Hysteria2-серверы, включая salamander и режим 1200 байт.
- TLS-тест проверяет доверенный сертификат, измерение задержки удалённого
  TLS и отказ при недоверенном сертификате.
- В iPhone Simulator проходят 2 UI-теста: импорт, переходы, настройки,
  HWID, настоящая тёмная тема, а также запуск проверки через заведомо
  закрытый VPN-порт с ожидаемой ошибкой. Прямого fallback нет.
- Снимки получены из настоящего приложения в iPhone 17 Pro Simulator.

работа и общесистемный VPN не заявляются.
