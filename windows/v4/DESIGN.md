# Windows Fluent: implementation references

The interface targets the Windows interpretation of Fluent, implemented in Qt.
It is not a WinUI application.

- [Microsoft Fluent iconography](https://fluent2.microsoft.design/iconography):
  use official system icons; regular for navigation/actions, filled for selected
  navigation. Icons are bundled SVGs, sized at 20 logical pixels, rendered at
  device pixel ratios 1 and 2. No emoji or text symbols represent actions.
- [Windows geometry](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry):
  4px control corners and in-page cards, 8px outer content surface and flyouts.
- [Fluent typography](https://fluent2.microsoft.design/typography): 14px body,
  12px captions, 16px section labels, 28px page titles; Segoe UI with Segoe UI
  Variable Display when available. Sentence case replaces all-caps headings.
- [NavigationView](https://learn.microsoft.com/en-us/windows/apps/design/controls/navigationview):
  left navigation, settings in its footer, neutral selected backplate with a
  short accent selection indicator.
- [Fluent motion](https://fluent2.microsoft.design/motion): short, eased transitions,
  page fade, progress interpolation, switch movement; user can disable motion.

Visual layers: base navigation surface, inset content surface, cards and input
surfaces. Blue highlights the primary action and selection indicator. Semantic
colors supplement status text. List selection remains neutral and text readable.

Official Microsoft Fluent System Icons source revision and MIT license are
bundled in `assets/SOURCE.txt` and `assets/Fluent-System-Icons-LICENSE.txt`.
All icons remain available offline and on systems without Segoe Fluent Icons.

## System accent ramp

The app reads the RGBx accent ramp generated by Windows from the current user's
Explorer/Accent/AccentPalette registry value. Its ordering and values were
cross-checked with UISettings.GetColorValue. Settings are never changed by the app.
Every two seconds the app checks for an updated ramp and refreshes only if it changed.
When Windows data is unavailable, the previous default blue palette is retained.

Role mappings follow Microsoft's
[WinUI theme resources](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/CommonStyles/Common_themeresources_any.xaml):

| Role | Dark theme | Light theme |
| --- | --- | --- |
| Primary accent fill | SystemAccentColorLight2 | SystemAccentColorDark1 |
| Primary accent text | SystemAccentColorLight3 | SystemAccentColorDark2 |
| Text on accent | Black | White |
| Accent fill on hover | Same accent, 90% opacity over card | Same accent, 90% opacity over card |
| Accent fill when pressed | Same accent, 80% opacity over card | Same accent, 80% opacity over card |

This mapping covers the primary button, progress, input focus, tabs, switch,
navigation selection indicator and accent icons. Brand artwork remains fixed.
